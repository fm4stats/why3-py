Command lines for the artifact evaluation

We present the command lines for artifact evaluation written in the appendix of our paper as follows.


0. How to run the first example
-------------------------------
Command lines:
 cd why3-py/
 ./env-why3 python3 examples/statwhy-python/example0_meta_pv.py

Output:
 eg_meta_pvs_fisher p-value : 0.115216


Command line:
 ./statwhy-py examples/statwhy-python/example0_meta_pv.py

Outcome:
The IDE is launched. Please refer to Appendix A.2 of our paper.


1. Functional outcome F1
------------------------
Command line (at the directory why3-py):
 ./statwhy-py examples/statwhy-python/example0_meta_pv.py

Outcome:
The IDE is launched and the verification will be successful after right-clicking the goal main'vc and selecting 'StatWhy'.
Please refer to Appendices A.2 and A.3 of our paper.


2. Functional outcome F2
------------------------
Command line (at the directory why3-py):
 ./statwhy-py examples/statwhy-python/FAIL_meta_pv.py

Outcome:
The IDE is launched and the verification will be FAILED after right-clicking the goal main'vc and selecting 'StatWhy'.
Note that this Python code has an incorrect annotation where several requirements for Fisher's method are missing and can be found by selecting '2 [precondition]' and the task tab and reading the goal that the tool could not prove.
Please refer to Section 3 and Appendix A.3 of our paper.


3. Functional outcome F3
------------------------
Command line (at the directory why3-py):
 ./env-why3 python3 examples/statwhy-python/example0_meta_pv.py

Output of the p-value:
 eg_meta_pvs_fisher p-value : 0.115216


4. Functional outcome F4
------------------------
Command line (at the directory why3-py):
 python3 examples/statwhy-python/bench.py tukey_hsd 3

Output of the execution time:
 tukey_hsd,3,StatWhy,25.946896076202393
